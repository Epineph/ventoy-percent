## Supported options

| Purpose | Options | Behavior |
| --- | --- | --- |
| Install (default) | `--install`, `-i` | Runs Ventoy `-i`; refuses an existing installation. |
| Reinstall | `--reinstall`, `--re-install`, `-I` | Runs Ventoy `-I`; erases existing disk data. |
| Update | `--update`, `-u`, `-U` | Runs Ventoy lowercase `-u`; preserves existing layout and ISO files. |
| Execute | `--execute` | Required to perform an operation; otherwise preview only. |
| First approval | `--apply` | Automatically approves the first confirmation. |
| Final approval | `--yes`, `--noconfirm`, `--noconfir` | Automatically approves the final confirmation. |
| Both approvals | `--apply --yes`, or `--force` | Automatically approves both; `--force` does not select reinstall. |
| Explicit verification | `--verify` | Implies `--apply --verbose`; always requires exact uppercase `YES`. |
| Extra information | `-v`, `--verbose` | Prints operation, command, sizing and disk metadata without changing approval requirements. |

`--verify` retains its mandatory `YES` prompt even with `--yes`, `--noconfirm`,
or `--force`. Other answers or closed input cancel before Ventoy starts.

When an automatic final-approval flag is used, the wrapper explains which
confirmation protections are disabled and waits three seconds after any required
manual approval. Ctrl+C can cancel. With both approvals automatic, it states:

> All remaining confirmation protections have been disabled for this operation;
> only an error may halt it.

This applies to **confirmation prompts**. Root, device, mount/swap/mapping,
read-only, sector and sizing checks remain enforced, along with Ventoy errors.

Without confirmation flags, Ventoy retains its native interactive prompts.
With those flags, the wrapper obtains the required approvals first, then supplies
exactly two native `y` answers for install/reinstall or one for update.

`--iso-percent` is required for installation/reinstallation. Updates do not resize
partitions and ignore `--iso-percent`, `-g`/`--gpt` and `-L`/`--label`.

## Commands discussed

Requested reinstall with full information and typed verification:

```sh
sudo ventoy-percent --execute --reinstall --iso-percent 15 -g -L iso_disk /dev/sda --apply --verify --verbose
```

Equivalent shorter form, since `--verify` implies `--apply --verbose`:

```sh
sudo ventoy-percent --execute -I --iso-percent 15 -g -L iso_disk /dev/sda --verify
```

Fully automatic reinstall, with the warning and three-second delay:

```sh
sudo ventoy-percent --execute --reinstall --iso-percent 15 -g -L iso_disk /dev/sda --apply --yes
```

Update with verification:

```sh
sudo ventoy-percent --execute --update /dev/sda --verify
```

Remove `--execute` to preview any operation without changing a disk.
Installation/reinstallation commands above erase the selected disk when approved.

## Known limitation and session resumption

Automatic answers follow Ventoy 1.1.18's prompt counts. Extra native prompts get
EOF, not additional approval. Ventoy may report success when cancelling on EOF,
so exit status alone cannot establish completion if a later version changes its
prompt flow. The README documents this limitation.
